# AI tooling for development

Explore the AI tools available to developers in the B.C. government. Learn what tools you can use, how to get access and the guidelines and recommendations that support their use. You'll also find links to B.C. government resources such as Agent Skills, along with a playbook that highlights proven examples.

## Where to start

- [Getting started](getting-started.md): Find the tools available, get access and set them up, and find training and help
- [General guidelines for AI-assisted development](guidelines.md): Learn the human-in-the-loop expectations and workflow guidance for working with AI tools
- [AI tooling security requirements](security/index.md): Learn the mandatory security requirements, including what information you may use and how to contain agents

## Before you use AI tools

Review the [AI tooling security requirements](security/index.md) and the [general guidelines](guidelines.md) before you use AI tools for development or in an application. They help you determine whether AI is suitable for your use case.
