# AI tooling for development

Looking to bring AI tools into your development workflow? Explore the tools available to B.C. government developers, learn how to get access and set them up. You can also find practical guidance to help you get the most out of AI-assisted development while working safely and responsibly.

## Where to start

These guides will help you find the right tools, integrate them into your development workflow and understand the requirements for using them safely.

- [Getting started and support](getting-started.md): Find available AI tools, check for access requirements, eligibility, set up tools and find training and support
- [General guidelines for AI-assisted development](guidelines.md): Learn recommended workflows and human-in-the-loop expectations for working with AI tools
- [AI tooling security requirements](security/index.md): Review mandatory security requirements, including what information you can use and how to contain agents

## Before you use AI tools

Before using AI tools, review the [AI tooling security requirements](security/index.md) and [general guidelines](guidelines.md) guidelines. The security requirements outline mandatory safeguards, while the general guidelines explain recommended practices for AI-assisted development.
